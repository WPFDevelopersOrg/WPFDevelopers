# wd:NotifyIcon

> 分类：[窗口与导航](../index.md#window-navigation) · 可通过 WPFDevelopers NuGet 包使用。

系统托盘图标

## 示例源码

[NotifyIconExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/NotifyIconExample.xaml)

## XAML 用法

```xml
<wd:NotifyIcon
                Title="WPFDevelopers - NotifyIcon 示例"
                Click="NotifyIcon_Click"
                Icon="pack://application:,,,/WPFDevelopers.Samples;component/WPFDevelopers.ico"
                MouseDoubleClick="NotifyIcon_MouseDoubleClick">
```
