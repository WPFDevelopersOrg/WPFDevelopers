# wd:NavMenu3D

> 分类：[窗口与导航](../index.md#window-navigation) · 可通过 WPFDevelopers NuGet 包使用。

3D 动画导航菜单

## 示例源码

[NavMenu3DExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/NavMenu3DExample.xaml)

## XAML 用法

```xml
<wd:NavMenu3D
                    x:Name="PART_NavMenu3D"
                    VerticalAlignment="Bottom"
                    SelectionChanged="NavMenu3D_SelectionChanged">
```
