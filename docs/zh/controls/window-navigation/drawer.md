# wd:Drawer

> 分类：[窗口与导航](../index.md#window-navigation) · 可通过 WPFDevelopers NuGet 包使用。

滑出式面板（上/下/左/右）

## 示例源码

[DrawerExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/DrawerExample.xaml)

## XAML 用法

```xml
<wd:Drawer
                x:Name="MyDrawerTop"
                Margin="2"
                Position="Top">
```
