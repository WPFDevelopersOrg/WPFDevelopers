# wd:SpotLight

> 分类：[动画与特效](../index.md#animation-effects) · 可通过 WPFDevelopers NuGet 包使用。

聚光灯效果

## 示例源码

[SpotLightExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/SpotLightExample.xaml)

## XAML 用法

```xml
<wd:SpotLight
                DefaultForeground="Crimson"
                FontFamily="Arial Black"
                FontSize="50"
                Foreground="Fuchsia"
                Text="YanJinHua"
                Duration="00:00:05" />
```
