# wd:AnimationAudio

> 分类：[动画与特效](../index.md#animation-effects) · 可通过 WPFDevelopers NuGet 包使用。

音频波形可视化

## 示例源码

[AnimationAudioExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/AnimationAudioExample.xaml)

## XAML 用法

```xml
<wd:AnimationAudio
                    x:Name="AnimationAudioLeft"
                    wd:ElementHelper.CornerRadius="4"
                    MouseDown="AnimationAudioLeft_MouseDown" />
```
