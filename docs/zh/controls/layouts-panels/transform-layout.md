# TransformLayout

> 分类：[布局与面板](../index.md#layouts-panels) · 该项目目前仅在示例程序中提供，不属于 NuGet 控件包。

可拖拽旋转缩放控件

## 示例源码

[TransformLayoutExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/TransformLayoutExample.xaml)

## XAML 用法

```xml
<controls:TransformLayout
                x:Name="MyTransformLayout"
                Canvas.Left="305"
                Canvas.Top="205"
                Width="280"
                Height="100">
```
