# wd:GestureUnlock

> 分类：[输入控件](../index.md#input-controls) · 可通过 WPFDevelopers NuGet 包使用。

手势解锁

## 示例源码

[GestureUnlockExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/GestureUnlockExample.xaml)

## XAML 用法

```xml
<wd:GestureUnlock
                        x:Name="myGestureUnlock"
                        wd:ElementHelper.CornerRadius="5"
                        Completed="GestureCompleted">
```
