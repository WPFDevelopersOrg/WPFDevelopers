# wd:NumericBox

> 分类：[输入控件](../index.md#input-controls) · 可通过 WPFDevelopers NuGet 包使用。

数字输入框

## 示例源码

[NumericBoxExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/NumericBoxExample.xaml)

## XAML 用法

```xml
<wd:NumericBox
                    Width="100"
                    Height="30"
                    IsAutoCapture="True"
                    Maximum="100"
                    Minimum="0"
                    Precision="2">
```
