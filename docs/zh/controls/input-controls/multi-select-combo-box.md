# wd:MultiSelectComboBox

> 分类：[输入控件](../index.md#input-controls) · 可通过 WPFDevelopers NuGet 包使用。

下拉多选框

## 示例源码

[MultiSelectComboBoxExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/MultiSelectComboBoxExample.xaml)

## XAML 用法

```xml
<wd:MultiSelectComboBox
                Width="200"
                HorizontalAlignment="Center"
                wd:ElementHelper.Watermark="请选择内容"
                Delimiter="^"
                IsSearch="False"
                IsSelectAllActive="True">
```
