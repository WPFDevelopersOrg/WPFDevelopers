# wd:TimePicker

> 分类：[输入控件](../index.md#input-controls) · 可通过 WPFDevelopers NuGet 包使用。

## 示例源码

[TimePickerExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/TimePickerExample.xaml)

## XAML 用法

```xml
<wd:TimePicker
                Width="200"
                VerticalAlignment="Center"
                wd:ElementHelper.Watermark="请选择任意时间" />
```
