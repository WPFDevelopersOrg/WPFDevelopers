# wd:SvgViewer

> 分类：[输入控件](../index.md#input-controls) · 可通过 WPFDevelopers NuGet 包使用。

SVG 查看器

## 示例源码

[SvgViewerExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/SvgViewerExample.xaml)

## XAML 用法

```xml
<wd:SvgViewer
                Width="50"
                Height="50"
                Source="pack://application:,,,/WPFDevelopers.Samples;component/Resources/Svg/Star.svg" />
```
