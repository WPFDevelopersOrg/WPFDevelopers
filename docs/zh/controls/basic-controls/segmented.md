# wd:Segmented

> 分类：[基础控件与样式](../index.md#basic-controls) · 可通过 WPFDevelopers NuGet 包使用。

分段控制器（多选项切换）

## 示例源码

[SegmentedExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/SegmentedExample.xaml)

## XAML 用法

```xml
<wd:Segmented
                    x:Name="HorizontalXAMLSegmented"
                    Width="300"
                    Height="60"
                    Padding="6"
                    ItemClick="Segmented_ItemClick"
                    SelectedIndex="0">
```
