# TransformLayout

> Category: [Layout & Panels](../index.md#layouts-panels) · Sample-only: this implementation is not included in the NuGet control package.

Draggable, resizable, rotatable control

## Example Source

[TransformLayoutExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/TransformLayoutExample.xaml)

## XAML Usage

```xml
<controls:TransformLayout
                x:Name="MyTransformLayout"
                Canvas.Left="305"
                Canvas.Top="205"
                Width="280"
                Height="100">
```
