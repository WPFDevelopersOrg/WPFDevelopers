# wd:WDScrollViewer

> Category: [Layout & Panels](../index.md#layouts-panels) · Available in the WPFDevelopers NuGet package.

A ScrollViewer control with smooth scrolling animation.

## Example Source

[ScrollViewerAnimationExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/ScrollViewerAnimationExample.xaml)

## XAML Usage

```xml
<wd:WDScrollViewer
                    Width="200"
                    MaxHeight="300"
                    IsScrollAnimation="True"
                    wd:ScrollViewerBehavior.IsBackToTopEnabled="True">
```
