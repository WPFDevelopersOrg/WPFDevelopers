## Example Source

[RollLoadingExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/Loading/RollLoadingExample.xaml)

## XAML Usage

```xml
<wd:RollLoading
                Width="200"
                HorizontalContentAlignment="Center"
                VerticalContentAlignment="Center"
                IsLoading="{Binding ElementName=MyCheckBox, Path=IsChecked}">
```
