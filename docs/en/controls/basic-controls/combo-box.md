# ComboBox

> Category: [Basic Controls & Styles](../index.md#basic-controls) · A standard WPF control; the linked sample demonstrates the WD theme style.

ComboBox (watermark / editable / corner radius)

## Example Source

[ComboBoxExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/Basics/ComboBoxExample.xaml)

## XAML Usage

```xml
<ComboBox
                    Margin="10,2"
                    wd:ElementHelper.Watermark="ComboBox"
                    Background="LightYellow"
                    FontSize="20"
                    Foreground="Black">
```
