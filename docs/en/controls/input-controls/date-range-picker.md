# wd:DateRangePicker

> Category: [Input Controls](../index.md#input-controls) · Available in the WPFDevelopers NuGet package.

Date range picker

## Example Source

[DateRangePickerExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/DateRangePickerExample.xaml)

## XAML Usage

```xml
<wd:DateRangePicker
                Width="300"
                Height="38"
                VerticalAlignment="Top"
                EndWatermark="结束日期"
                IsSyncingDisplayDate="True"
                StartWatermark="开始日期" />
```
