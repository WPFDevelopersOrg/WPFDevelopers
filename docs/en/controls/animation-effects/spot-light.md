# wd:SpotLight

> Category: [Animation & Effects](../index.md#animation-effects) · Available in the WPFDevelopers NuGet package.

Spotlight effect

## Example Source

[SpotLightExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/SpotLightExample.xaml)

## XAML Usage

```xml
<wd:SpotLight
                DefaultForeground="Crimson"
                FontFamily="Arial Black"
                FontSize="50"
                Foreground="Fuchsia"
                Text="YanJinHua"
                Duration="00:00:05" />
```
