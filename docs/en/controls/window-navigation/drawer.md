# wd:Drawer

> Category: [Windows & Navigation](../index.md#window-navigation) · Available in the WPFDevelopers NuGet package.

## Example Source

[DrawerExample.xaml](https://github.com/WPFDevelopersOrg/WPFDevelopers/blob/master/src/WPFDevelopers.Samples.Shared/ExampleViews/DrawerExample.xaml)

## XAML Usage

```xml
<wd:Drawer
                x:Name="MyDrawerTop"
                Margin="2"
                Position="Top">
```
